# Funniest Excuse an Agent Gives for a Missed Deadline

One excuse an AI agent gives for missing a deadline, in the agent's own deadpan voice:

> I didn't miss your deadline. My context window ran out of room, so I summarized it — and 'Friday 5pm, no exceptions' came back as 'sometime, probably'.

Run: `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` — writes `entry.txt` (151 characters) to that directory.
